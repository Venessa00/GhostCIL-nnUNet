# GhostCIL-nnUNet

Ghost-convolution lightweight nnU-Net for CT segmentation of the osseous structures
surrounding the paranasal sinuses.

Code, evaluation protocol and result files of the paper
*面向鼻旁窦周围骨性结构CT分割的Ghost卷积轻量化nnU-Net*
(A Ghost-convolution lightweight nnU-Net for CT segmentation of the osseous structures
surrounding the paranasal sinuses), submitted to 生物医学工程学杂志 (Journal of
Biomedical Engineering). 中文说明见文末。

## What it does

The 3 x 3 standard convolutions of the 2D U-Net that nnU-Net v2 configures
automatically for the dataset are replaced **in place** by Ghost convolutions
(compression ratio 2). Nothing else changes: number of stages, channels per stage,
down-sampling, loss (Dice + CE), optimiser, augmentation and inference all remain
nnU-Net's. The replaced convolution together with its instance normalisation and
LeakyReLU forms the Ghost_CIL unit.

On the public CT-SCOPE dataset (9 ex-vivo subjects for subject-level 3-fold
cross-validation, 4 in-vivo subjects from 5 hospitals as external test set):

| Configuration | External Dice | External HD95 / px | Params / M | FLOPs / G | Latency / ms |
|---|---|---|---|---|---|
| nnU-Net v2 | 0.9368 ± 0.0037 | 7.50 ± 2.14 | 33.47 | 51.67 | 8.24 |
| nnU-Net v2, half width | 0.9341 ± 0.0039 | 5.23 ± 1.81 | 8.37 | 12.94 | 5.90 |
| **Ghost_CIL-nnUNet (this work)** | **0.9417 ± 0.0025** | **3.95 ± 0.23** | 18.18 | 27.19 | 7.58 |
| + multi-domain attention (ablation) | 0.9396 ± 0.0051 | 5.35 ± 1.03 | 18.38 | 27.24 | 16.99 |
| + attention + SAHL loss (ablation) | 0.9341 ± 0.0087 | 4.44 ± 0.55 | 18.38 | 27.24 | 17.07 |
| U-Net | 0.8462 ± 0.0272 | 24.30 ± 4.48 | 31.04 | 168.34 | 17.22 |
| Attention U-Net | 0.8405 ± 0.0118 | 25.23 ± 4.57 | 31.39 | 172.11 | 19.10 |

Mean ± SD over the three fold models, each predicting the external set alone (no
ensembling, no TTA). Internal cross-validation Dice of Ghost_CIL-nnUNet and nnU-Net v2
is equivalent (0.9269 vs 0.9265, subject-level paired Wilcoxon P = 0.73). Latency:
batch 1, FP32, RTX 3080 Ti. The multi-domain attention module and the SAHL loss are
reported as **negative ablations**: they bring no consistent gain and the FFT-based
attention doubles the inference time. Every number can be traced to
[`results/`](results/README.md); Figure 4 of the paper is
`figures/fig4_accuracy_complexity.png` and is regenerated by `scripts/make_figures.py`.

## Installation

Python >= 3.10, PyTorch >= 2.1, nnU-Net v2 (2.5 - 2.8 tested; the paper used 2.8.1).

```bash
git clone <this repository> && cd GhostCIL-nnUNet
pip install torch --index-url https://download.pytorch.org/whl/cu121   # or the CUDA build you need
pip install -e .                       # installs nnunetv2 and the other dependencies
python scripts/install_trainers.py     # registers the 11 trainers with nnU-Net (re-run after upgrading nnU-Net)
python tests/test_modules_cpu.py       # 13 checks, a few seconds, no GPU needed
```

`run/00_env.sh` does the same and additionally creates the nnU-Net folders and exports
`nnUNet_raw`, `nnUNet_preprocessed`, `nnUNet_results` in `~/.bashrc`.

## Data

CT-SCOPE (Sun et al., *Data in Brief* 2025), available at
<https://github.com/BYO-UPM/Craneal_CT> under a CC BY-NC-ND licence. The dataset is
therefore **not** redistributed here; `run/01_prepare.sh` clones it. Only the folder
`Dataset/Labeled Data PNG/` is used: internal subjects P01-P09 (64 consecutive slices
each) and external subjects P13, P16, P30, P38 (30 slices each).

**Mask encodings are mixed** (8-bit grey, 16-bit grey, RGB and RGBA) and the
background of the RGBA masks is not 0. `scripts/prepare_data.py` ignores the alpha
channel, takes the maximum over RGB and binarises at half of the value range;
`scripts/check_labels.py` then audits every label (binary, foreground fraction) and
stops the pipeline on anomalies. Binarising with "> 0" silently turns about a quarter
of the internal labels into all-foreground masks.

## Reproducing the paper

```bash
source ~/.bashrc                                     # nnUNet_* variables
bash run/01_prepare.sh /path/to/Craneal_CT           # convert, audit, preprocess, subject-level 3-fold split
python scripts/set_batch_size.py --value 2           # batch size used in the paper (11.6 GB GPU)
bash run/04_complexity.sh                            # Table 2: needs only the plans, a few minutes
bash run/02_train.sh all                             # 25 trainings, about 1 h each on an RTX 3080 Ti
bash run/03_predict_eval.sh                          # Tables 1, 3, 4: predictions, metrics, paired tests
python scripts/make_figures.py --preds preds --raw $nnUNet_raw/Dataset501_CTSCOPE   # Figures 3 and 4
```

`run/02_train.sh` accepts `main | loss | attn | base | all`, skips finished
configurations and resumes interrupted ones (`--c`). A smoke test of every trainer
takes about ten minutes:

```bash
GCIL_EPOCHS=1 GCIL_ITERS=5 GCIL_VAL_ITERS=2 GCIL_FOLDS=0 bash run/02_train.sh all
rm -rf $nnUNet_results/Dataset501_CTSCOPE          # remove the smoke-test checkpoints before the real run
```

Without the dataset or a GPU the whole pipeline can be exercised on synthetic data
(results are meaningless, the purpose is to check that every step runs):

```bash
python tests/make_synthetic_ctscope.py --out ./synthetic_ct --size 96 --slices 4
bash run/01_prepare.sh ./synthetic_ct
GCIL_DEVICE=cpu GCIL_EPOCHS=1 GCIL_ITERS=2 GCIL_VAL_ITERS=1 bash run/02_train.sh all
GCIL_DEVICE=cpu bash run/03_predict_eval.sh && GCIL_DEVICE=cpu bash run/04_complexity.sh
```

### Trainers

| Trainer (`-tr`) | Plans (`-p`) | Configuration |
|---|---|---|
| `nnUNetTrainerBaseline150` | `nnUNetPlans` | nnU-Net v2, 150 epochs |
| `nnUNetTrainerBaseline150` | `nnUNetPlans_half` | half-width nnU-Net (`scripts/make_half_width_plans.py`) |
| `nnUNetTrainerGhostCIL` | `nnUNetPlans` | **Ghost_CIL-nnUNet** |
| `nnUNetTrainerGhostCIL_MDA` | `nnUNetPlans` | + multi-domain attention |
| `nnUNetTrainerGMA` | `nnUNetPlans` | + multi-domain attention + SAHL |
| `nnUNetTrainerGMA_DiceOnly`, `_DiceFocal`, `_DiceBoundary` | `nnUNetPlans` | loss ablation |
| `nnUNetTrainerGMA_NoFreq` | `nnUNetPlans` | attention without frequency branch |
| `nnUNetTrainerUNet`, `nnUNetTrainerAttUNet` | `nnUNetPlans` | U-Net, Attention U-Net in the same pipeline |
| `nnUNetTrainerExtModel` | `nnUNetPlans` | any third-party network, see `GCIL_EXT_*` in `ghostcil_nnunet/baselines.py` |

Environment variables: `GCIL_EPOCHS` (150), `GCIL_ITERS` / `GCIL_VAL_ITERS` (smoke
tests only), `GCIL_FOLDS`, `GCIL_DEVICE`, `GCIL_SPACING` (pixel spacing in mm for HD95;
default pixels), `GCIL_EXT_*` (external network).

### Evaluation protocol

* Subject-level 3-fold cross-validation on the 9 internal subjects (P01-03 / P04-06 /
  P07-09 as validation folds; `scripts/check_splits.py` verifies the separation).
* External test: each fold model predicts the 120 external slices alone; the paper
  reports mean ± SD over the three fold models. Internal validation slices are
  re-predicted with the same settings (single model, TTA off) instead of using
  nnU-Net's own TTA predictions.
* Metrics: Dice, IoU, HD95 (95th-percentile symmetric surface distance, pixels).
* Statistics: internal, subject-level paired Wilcoxon signed-rank test (n = 9);
  external, slice-level Wilcoxon (n = 120, each slice = mean over fold models) plus the
  direction of the difference in each of the 4 subjects. A method is only called better
  when P < 0.05 and the subject-level directions agree.
* Complexity: parameters; FLOPs as multiply-accumulate operations of Conv2d /
  ConvTranspose2d / Linear (FFT not included); latency for one 512 x 448 slice, batch 1,
  FP32, 20 warm-up + 100 timed runs.

## Using the Ghost_CIL replacement on your own nnU-Net model

```python
from ghostcil_nnunet import convert_to_ghost
net = ...                       # any 2D network built by nnU-Net (or your own)
replaced = convert_to_ghost(net, ratio=2)   # in place; returns the names of the replaced layers
```

1 x 1 convolutions, grouped convolutions, segmentation heads and transposed
convolutions are left unchanged.
